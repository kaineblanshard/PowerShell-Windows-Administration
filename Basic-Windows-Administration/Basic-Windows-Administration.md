# Basic Windows Administration Using PowerShell

## Overview

This project covers practical exercises using PowerShell to manage files, folders and running processes in Windows.

The aim was to become more comfortable using PowerShell and understand how it can be used to carry out everyday Windows administration tasks.

## Work Completed

### File and Folder Management

- Created text files containing directory information.
- Viewed the contents of text files.
- Renamed existing files.
- Created folders to organise files.
- Copied files between locations.
- Moved files into different folders.
- Deleted files when no longer needed.

### Process Management

- Used PowerShell to list running processes.
- Saved a list of running processes into a text file.
- Moved the exported file into a separate folder.
- Viewed the contents of the exported file.

## Skills Developed

- Navigating Windows directories.
- Managing files and folders using PowerShell.
- Retrieving information about running processes.
- Saving command output to text files.
- Using different commands and methods to achieve the same result.

## Learning and Problem Solving

I didn't always use exactly the same commands or methods shown in the learning material. For some exercises, I found alternative ways to achieve the same outcome.

This helped me understand that there is often more than one way to complete a task using PowerShell.

My focus was on understanding the commands and successfully completing the tasks rather than simply copying examples.
