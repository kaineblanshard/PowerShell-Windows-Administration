# PowerShell - Learning Windows Administration

## About

I've started learning PowerShell to improve my Windows administration skills and become more confident using it in everyday IT support.

I'm using practical exercises and books to learn different commands, understand how they work and see how they can be used to manage Windows systems.

The aim is to build my knowledge gradually and eventually become comfortable using PowerShell for tasks that would normally be done through the Windows interface.

## What I'm Learning

So far, I'm focusing on:

- Creating, copying, moving and deleting files and folders.
- Checking running processes and managing them.
- Learning how Windows services work.
- Getting information about Windows computers.
- Understanding basic PowerShell scripts.
- Managing Active Directory users and groups.
- Looking at ways to automate repetitive tasks.

## Practical Work

### Completed
- **Basic Windows Administration:** Practised working with files, folders and running processes using PowerShell commands.

### In Progress
- **PowerShell Scripting:** Learning how to put commands together and create simple scripts.
- **Active Directory:** Practising how to manage users and groups using PowerShell.

### Still to Cover
- **Windows Services:** Learning how to check, start and stop services.
- **System Information:** Using PowerShell to find useful information about a computer.
- **Automation:** Looking at how PowerShell can make repetitive IT support tasks easier.

## What I'm Trying to Achieve

I don't want to just memorise commands without understanding them.

I'm trying to learn what each command does, when it would be useful and how it could help with real IT support tasks.

I'll keep adding to this as I practise new commands and become more confident using PowerShell.
