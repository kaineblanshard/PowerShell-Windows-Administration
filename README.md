# PowerShell – Windows Administration

## About This Project

This repository documents my practical learning and development of PowerShell, with a focus on Windows administration and IT support.

I'm using hands-on exercises to build my understanding of PowerShell commands, manage Windows systems and gradually develop the skills needed to automate everyday IT tasks.

## Areas of Learning

- File and folder management
- Windows process management
- Windows services
- System information
- PowerShell scripting
- Active Directory administration
- Task automation

## Practical Work

| Project | Description | Status |
|---|---|---|
| Basic Windows Administration | Managing files, folders and running processes using PowerShell | Completed |
| PowerShell Scripting | Developing and practising basic scripts | In progress |
| Windows Services | Learning to manage and investigate Windows services | Planned |
| System Information | Retrieving useful information from Windows systems | Planned |
| Active Directory | Practising user and group administration using PowerShell | Planned |

## Learning Approach

My focus is on understanding Powershell not just memorising commands. I aim to understand what each command does, find different ways to achieve tasks and apply what I learn to real-world IT support situations.

This repository will be updated as I complete further exercises and develop my skills.
